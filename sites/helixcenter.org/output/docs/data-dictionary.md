# Data Dictionary

Field-by-field reference for every content type in the Helix Center site rebuild. Documents the mapping from WordPress REST API fields and HTML-scraped data to Prisma schema fields, including types, constraints, sample values, and transformation notes.

---

## Roundtable

WordPress endpoint: `/wp-json/wp/v2/roundtable`

Additional sources: `roundtable_details.json` (HTML scraping), Yoast SEO fields from `wp_posts.json`

Prisma model: `Roundtable`

| Source / Field Path | Prisma Field | Type | Required | Sample Value | Transformation Notes |
|---|---|---|---|---|---|
| `id` | `wpId` | `Int` | Yes | `2767` | WordPress post ID. Stored for cross-referencing during seed. Unique constraint. |
| `slug` | `slug` | `String` | Yes | `"see-memory"` | URL-safe slug. Used as the route parameter (`/roundtables/[slug]`). Unique constraint. |
| `title.rendered` | `title` | `String` | Yes | `"See Memory"` | HTML-encoded string. Must be decoded: `&#8217;` becomes `'`, `&amp;` becomes `&`, etc. Use a library like `he` or `html-entities`. |
| `content.rendered` | `content` | `String` | Yes | `"<p>This roundtable explores...</p>"` | Full WordPress HTML content including inline styles, `<figure>` blocks, and embedded media. Preserve as-is; do not strip tags. |
| `excerpt.rendered` | `excerpt` | `String` | Yes | `"<p>A discussion on visual memory...</p>"` | Short HTML excerpt auto-generated by WordPress. Contains `<p>` tags. |
| `date` | `publishedAt` | `DateTime` | Yes | `"2025-10-04T13:00:00"` | ISO 8601 format. Parse with `new Date()`. WordPress returns in site timezone (America/New_York). |
| `modified` | `updatedAt` | `DateTime` | Yes | `"2025-10-10T09:30:00"` | ISO 8601. Last modified timestamp. |
| `status` | `status` | `String` | Yes | `"publish"` | Post status. Only `"publish"` posts should be imported. |
| `link` | `sourceUrl` | `String` | Yes | `"https://helixcenter.org/roundtable/see-memory/"` | Original WordPress permalink. Stored for redirect mapping. |
| `featured_media` | `featuredMediaId` | `Int?` | No | `2770` | WordPress media attachment ID. Must be cross-referenced with the Media table to get the actual image URL. Value is `0` when no featured image is set. Treat `0` as `null`. |
| `meta.audio_file` | `audioFile` | `String?` | No | `"https://media.helixcenter.org/podcasts/audio/251004_SeeMemory.mp3"` | Direct URL to the MP3 file. Not all roundtables have audio. Empty string should be treated as `null`. |
| `meta.duration` | `audioDuration` | `String?` | No | `"1:08:20"` | Pre-formatted duration string (H:MM:SS or MM:SS). Stored as-is; no parsing needed. |
| `meta.filesize` | `audioFilesize` | `String?` | No | `"75.33M"` | Human-readable file size. Stored as-is. |
| `meta.date_recorded` | `dateRecorded` | `DateTime?` | No | `"2025-10-04"` | Date the roundtable was recorded. Format is `YYYY-MM-DD`. Parse with `new Date(value + "T00:00:00")` to avoid timezone shifts. |
| `meta.episode_type` | `episodeType` | `String?` | No | `"audio"` | Always `"audio"` when present. |
| `tags[]` | via `RoundtableTag` | `Int[]` | No | `[45, 67, 123]` | Array of WordPress tag IDs. Each ID maps to a `Tag` record via the `RoundtableTag` join table. |
| `series[]` | `seriesId` | `Int?` | No | `[89]` | Array of WordPress series term IDs (custom taxonomy). In practice, a roundtable belongs to at most one series. Map to `Series` model via term ID lookup. |
| **Scraped from roundtable HTML pages** (`roundtable_details.json`) | | | | | |
| `p.mb-1` text | `eventDatetime` | `String?` | No | `"October 4th, 2025 at 2:00PM"` | Scraped from the `<p class="mb-1">` element on the roundtable HTML page. Contains a human-readable event date and time. 135/135 roundtables have this value. Stored as-is; no parsing into a `DateTime` -- the format varies. |
| `span.badge` inside `p.mb-1` | `eventStatus` | `String?` | No | `"Past Event"` | Scraped from the `<span class="badge">` element nested inside the date paragraph. Values are `"Past Event"` or `"Future Event"`. |
| `iframe[src*=youtube]` | `videoUrl` | `String?` | No | `"https://www.youtube.com/embed/xxx"` | Scraped from the YouTube embed iframe `src` attribute on the roundtable HTML page. 127/135 roundtables have a video. The remaining 8 are either upcoming events or have no recording. |
| **Yoast SEO fields from** `wp_posts.json` | | | | | |
| `meta.filesize_raw` | `audioFilesizeRaw` | `String?` | No | `"135721586"` | Raw audio file size in bytes as a string. Complements the human-readable `audioFilesize` field. Can be parsed to `Int` for size comparisons. |
| `meta.download_link` | `downloadLink` | `String?` | No | `"https://helixcenter.org/podcast-download/..."` | Podcast download URL. Used for the download button on the roundtable detail page. |
| `meta.player_link` | `playerLink` | `String?` | No | `"https://helixcenter.org/podcast-player/..."` | Podcast player URL. Used for embedding the podcast player widget. |
| `yoast_head_json.og_description` | `ogDescription` | `String?` | No | `"A discussion on visual memory and..."` | Truncated description for social sharing (Open Graph). Use as the `<meta property="og:description">` tag. |
| `yoast_head_json.og_image[0].url` | `ogImageUrl` | `String?` | No | `"https://media.helixcenter.org/wp-content/uploads/..."` | Social sharing image URL (Open Graph). Use as the `<meta property="og:image">` tag. |
| `yoast_head_json.canonical` | `canonicalUrl` | `String?` | No | `"https://helixcenter.org/roundtable/see-memory/"` | Canonical URL for SEO. Use as the `<link rel="canonical">` tag. May differ from `sourceUrl` if WordPress applied canonical overrides. |

## Page

WordPress endpoint: `/wp-json/wp/v2/pages`

Prisma model: `Page`

| WP Field Path | Prisma Field | Type | Required | Sample Value | Transformation Notes |
|---|---|---|---|---|---|
| `id` | `wpId` | `Int` | Yes | `40` | WordPress page ID. Unique constraint. |
| `slug` | `slug` | `String` | Yes | `"about"` | URL slug. Unique constraint. |
| `title.rendered` | `title` | `String` | Yes | `"About"` | HTML-decode as with other titles. |
| `content.rendered` | `content` | `String` | Yes | `"<p>The Helix Center is...</p>"` | Full HTML content. Preserve as-is. |
| `parent` | `parentId` | `Int?` | No | `40` | WordPress parent page ID. Value `0` means top-level page; treat as `null`. During seed, resolve WP parent ID to the local `Page.id` by looking up `Page.wpId`. |

### Page Hierarchy

The following hierarchy is derived from the WordPress `parent` field:

```
About (wpId=40, parent=0)                    → /about
├── Board of Directors (wpId=702, parent=40) → /about/board-of-directors
├── Executive Committee (wpId=365, parent=40)→ /about/executive-committee
├── Arts/Humanities (wpId=368, parent=40)    → /about/arts-humanities
├── Music (wpId=372, parent=40)              → /about/music
├── Film (wpId=374, parent=40)               → /about/film
└── Digital (wpId=376, parent=40)            → /about/digital
```

Routes for child pages are constructed as `/{parent-slug}/{child-slug}`. The seed script must resolve `parent` (WP ID) to the local auto-incremented `Page.id`.

### Prisma Schema

```prisma
model Page {
  id          Int      @id @default(autoincrement())
  wpId        Int      @unique
  slug        String   @unique
  title       String
  content     String
  parentId    Int?

  parent      Page?    @relation("PageHierarchy", fields: [parentId], references: [id])
  children    Page[]   @relation("PageHierarchy")

  createdAt   DateTime @default(now())
}
```

## Join Tables

### RoundtableTag

Maps the many-to-many relationship between roundtables and tags.

| Field | Type | Description |
|---|---|---|
| `roundtableId` | `Int` | Foreign key to `Roundtable.id` |
| `tagId` | `Int` | Foreign key to `Tag.id` |

**Source**: The `tags[]` array on each WordPress roundtable post contains WP tag IDs. During seed, look up the local `Roundtable` by `wpId` and the local `Tag` by `wpId`, then create the join record.

```prisma
model RoundtableTag {
  roundtable   Roundtable @relation(fields: [roundtableId], references: [id])
  roundtableId Int
  tag          Tag        @relation(fields: [tagId], references: [id])
  tagId        Int

  @@id([roundtableId, tagId])
}
```

### RoundtableParticipant

Maps the many-to-many relationship between roundtables and participants.

| Field | Type | Description |
|---|---|---|
| `roundtableId` | `Int` | Foreign key to `Roundtable.id` |
| `participantId` | `Int` | Foreign key to `Participant.id` |

**Source**: `roundtable_participants.json` (scraped from HTML, not from the REST API).

File structure:

```json
{
  "see-memory": [
    {
      "slug": "michael-coffey",
      "name": "Michael Coffey",
      "link": "https://helixcenter.org/participant/michael-coffey/"
    },
    {
      "slug": "jane-doe",
      "name": "Jane Doe",
      "link": "https://helixcenter.org/participant/jane-doe/"
    }
  ],
  "another-roundtable": [...]
}
```

**Seed logic**:

1. Iterate over each key (roundtable slug) in the JSON.
2. Look up `Roundtable` by `slug`. If not found, log a warning and skip.
3. For each participant object in the array, look up `Participant` by `slug`. If not found, log a warning and skip.
4. Create the `RoundtableParticipant` join record.

**Statistics**: 690 total relationships across 125 roundtables.

```prisma
model RoundtableParticipant {
  roundtable   Roundtable  @relation(fields: [roundtableId], references: [id])
  roundtableId Int
  participant  Participant @relation(fields: [participantId], references: [id])
  participantId Int

  @@id([roundtableId, participantId])
}
```

## Input Data Files

In addition to the WordPress REST API JSON exports (`wp_posts.json`, `wp_participants.json`, `wp_media.json`), the following supplementary data files provide fields not available through the API.

### `participant_titles.json`

Source: HTML scraping of individual participant pages.

Entries: 519 (keyed by participant slug).

Structure:

```json
{
  "michael-coffey": {
    "professional_title": "Professor of History, Yale University",
    "has_papers": false,
    "papers_text": null
  },
  "jane-doe": {
    "professional_title": "Director, Institute for Advanced Study",
    "has_papers": true,
    "papers_text": "'The Role of Memory in...' (2023), 'Cognition and...' (2021)"
  }
}
```

**Seed logic**: Iterate over each key (participant slug). Look up the `Participant` by `slug`. If found, update `professionalTitle`, `hasPapers`, and `papersText` from the corresponding fields.

### `roundtable_details.json`

Source: HTML scraping of individual roundtable pages.

Entries: 135 (keyed by roundtable slug).

Structure:

```json
{
  "see-memory": {
    "event_datetime": "October 4th, 2025 at 2:00PM",
    "event_status": "Past Event",
    "video_url": "https://www.youtube.com/embed/xxx",
    "participants_with_titles": [
      {
        "slug": "michael-coffey",
        "name": "Michael Coffey",
        "title": "Professor of History, Yale University"
      }
    ]
  }
}
```

**Seed logic**: Iterate over each key (roundtable slug). Look up the `Roundtable` by `slug`. If found, update `eventDatetime`, `eventStatus`, and `videoUrl` from the corresponding fields. The `participants_with_titles` array is informational and overlaps with `roundtable_participants.json`; prefer the latter for building `RoundtableParticipant` join records.

### `wp_series.json`

Source: WordPress REST API series taxonomy endpoint (`/wp-json/wp/v2/series`).

Entries: 1.

Structure:

```json
[
  {
    "id": 89,
    "slug": "consciousness",
    "name": "Consciousness",
    "description": "An ongoing exploration of consciousness..."
  }
]
```

**Seed logic**: Standard WordPress taxonomy import. Each entry maps directly to a `Series` record. The `description` field is new and should be stored as-is (treat empty string as `null`).

## Transformation Reference

### HTML Entity Decoding

WordPress encodes special characters in `title.rendered` and `name` fields. These must be decoded before storing in the database.

| Encoded | Decoded | Context |
|---|---|---|
| `&#8217;` | `'` | Right single quotation mark (curly apostrophe) |
| `&#8216;` | `'` | Left single quotation mark |
| `&#8220;` | `"` | Left double quotation mark |
| `&#8221;` | `"` | Right double quotation mark |
| `&#8211;` | `--` | En dash |
| `&#8212;` | `---` | Em dash |
| `&amp;` | `&` | Ampersand |
| `&lt;` | `<` | Less than |
| `&gt;` | `>` | Greater than |

**Recommended approach**: Use the `he` npm package:

```typescript
import he from "he";

const decodedTitle = he.decode(wpPost.title.rendered);
// "The Mind&#8217;s Eye" → "The Mind's Eye"
```

### Date Parsing

| Field | Input Format | Parsing Strategy |
|---|---|---|
| `date` | `"2025-10-04T13:00:00"` | `new Date(value)` -- WordPress returns local time (America/New_York). |
| `modified` | `"2025-10-10T09:30:00"` | `new Date(value)` |
| `meta.date_recorded` | `"2025-10-04"` | `new Date(value + "T00:00:00")` -- Append time component to prevent timezone offset issues. |

### Null Value Handling

Several WordPress fields use sentinel values instead of `null`:

| Field | Sentinel Value | Treatment |
|---|---|---|
| `featured_media` | `0` | Store as `null` |
| `parent` | `0` | Store as `null` |
| `meta.audio_file` | `""` (empty string) | Store as `null` |
| `meta.duration` | `""` (empty string) | Store as `null` |
| `meta.filesize` | `""` (empty string) | Store as `null` |
| `alt_text` | `""` (empty string) | Store as `null` |
| `caption.rendered` | `""` (empty string) | Store as `null` |
| `description` (Series) | `""` (empty string) | Store as `null` |

### Edge Cases

| Scenario | Count | Handling |
|---|---|---|
| Roundtables with no participant data | 10 | Typically upcoming events or special sessions. These will have an empty `participants` relation. |
| Participants with no roundtable data | 9 | May be board members, advisory roles, or inactive participants. Stored normally; their detail page will show "No roundtables" instead of a list. |
| Roundtables with no audio file | varies | The `audioFile` field will be `null`. The `<AudioPlayer />` component should not render. |
| Roundtables with no featured image | varies | The `featuredMediaId` field will be `null`. Cards and detail pages fall back to a placeholder. |
| Pages with no parent | varies | Top-level pages. `parentId` is `null`. Route is `/{slug}`. |
| Roundtables with no video | 8 | The `videoUrl` field will be `null`. Typically upcoming events or roundtables without a YouTube recording. The video embed component should not render. |
| Participants with no professional title | 67 | The `professionalTitle` field will be `null`. The title line below the name on the participant detail page should not render. |
| Participants with papers | 43 | `hasPapers` is `true` and `papersText` contains scraped text (up to 1000 chars). Render a "Papers & Presentations" section on the detail page. |
| Duplicate slugs across content types | 0 | Roundtable and participant slugs do not collide because they live in separate tables and route namespaces (`/roundtables/` vs `/participants/`). |
